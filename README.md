# SKATELINE

Hybrid free-roam skate game (Three.js).

## Play

https://skateline.vercel.app

## Controls

- W / Up — push
- A/D / Left/Right — lean
- Space — ollie
- Shift — grab
- Ctrl — crouch
- R — respawn
- P — pause

## World

Dense procedural skate-park city: buildings with windows, 12+ rails, ledges, stairs, ramps, funboxes, benches, lamps, trees, planters.
